# GF 因子 DSL 全量算子表

当前 DSL 共有 **58 个函数算子**，另支持 `+`、`-`、`*`、`/`、`**`、一元正负号和括号。下表是 worker、本地校验器和 LLM 提示词共同遵循的完整目录。

滚动窗口和位移 `n` 必须是正整数字面量。滚动算子至少需要 `max(3, floor(n/2))` 个有效观测；不足时输出 `NaN`。所有除法的零分母、无定义数学运算和无穷值均按缺失值处理。

## 财务数据时点规则

财务季度算子以会计期间 `report` 寻找上季或去年同期，但结果只从对应公告日 `dt` 起进入交易日面板；周末或节假日公告从下一交易日可见。它们不会用 63/252 个交易日位移模拟 QOQ/YOY。默认加载器为财务字段保留五年公告历史，以覆盖 SUD 的 12 季度最低历史需要，同时仍只读取表达式实际引用的字段。

财务字段写成 `balance__字段名`、`income__字段名` 或 `cashflow__字段名`。`IndusProp` 和 `DeltaProp` 使用远端 `industry_ci.parquet`：loader 固定过滤 `level == "中信一级"`，排除 `indus_code` 以 `CIHK` 开头的港股镜像记录，再依据 `beg_date <= dt <= end_date` 把境内 `CI...` 代码映射到每个交易日。行业代码而非名称参与分组，以保证标识稳定并避免文本编码差异。

## 维护一致性

算子实现与注册表位于 `scripts/gf_quant_remote_worker.py`，本地提交前校验位于 `rdagent/scenarios/gf_quant/developer/coder.py`，面向模型的静态说明位于 `rdagent/scenarios/gf_quant/experiment/prompts.yaml`。测试会检查两份注册表、函数签名和字段集合完全一致。

### 不采纳算子的主要原因

未采纳项主要分为四类：一是能够由现有算子直接组合，新增别名会制造重复表达式；二是无窗口累计类算子依赖数据加载起始日，换一个回测起点可能改变结果；三是离散化、单调缩放或大量数学函数对当前 RankIC 因子搜索的增量有限，反而会膨胀搜索空间；四是 `DSYOY`、`CumA2B` 等财务候选仍需先明确季节调整、单季值/累计值及 TTM 口径，暂不把不稳定定义固化进 DSL。
